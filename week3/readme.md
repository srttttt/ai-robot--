# 第三周实验报告：ROS2 Python开发与机器人仿真

## 实验内容

本周主要学习了 Python 编程基础、ROS2 Python 节点开发以及机器人仿真控制相关内容，同时进一步接触了 PyBullet 三维物理仿真环境与智能机器人控制流程。通过本周实验，初步掌握了 ROS2 中 Python 节点的基本开发方式，并能够实现对 TurtleSim 小乌龟的运动控制，同时了解了 3D 机器人仿真的基本原理以及智能机器人系统的整体结构。

本周完成的主要任务如下：

* 学习 Python 基础知识（数据类型、函数、类、循环、条件判断等）
* 学习 ROS2 Python 库 `rclpy` 的基本使用方法
* 编写第一个 ROS2 Python 节点（Hello World）
* 实现 TurtleSim 小乌龟直线运动控制
* 实现机器人按照固定路径移动
* 学习 PyBullet 三维仿真环境基础
* 了解 OpenClaw 与 RosClaw 智能机器人控制流程
* 初步接触自然语言控制机器人系统

通过这些实验内容，进一步理解了机器人软件开发中的通信机制、运动控制方式以及仿真系统的工作原理。

例如，在 ROS2 中，一个节点通常会写成：

```python id="w5n2vr"
class HelloNode(Node):
    def __init__(self):
        super().__init__('hello_node')
```

通过本部分学习，理解了类初始化、成员函数以及对象调用等概念，同时也进一步提高了 Python 代码阅读能力与调试能力。

## ROS2 Python 节点开发

随后学习了 ROS2 Python 库 `rclpy` 的基本使用方法，并成功编写了第一个 ROS2 Python 节点。

运行命令：

```bash id="q7m4xt"
python3 hello_node.py
```

节点运行后，终端能够持续输出 Hello World 信息，说明节点已经正常启动。

在 ROS2 中，一个完整节点通常包括：

* `rclpy.init()` 初始化
* 创建 Node 对象
* 创建 Publisher 或 Subscriber
* `rclpy.spin()` 保持节点运行
* `destroy_node()` 销毁节点

通过本次实验，理解了 ROS2 节点生命周期与消息通信机制。同时也学习了 ROS2 中“节点”的概念，即不同功能模块之间通过消息实现通信，每个节点负责不同任务。

通过观察终端输出，可以确认 ROS2 环境已经正确安装，并且 Python 节点能够正常运行。

## TurtleSim 小乌龟控制实验

完成基础节点开发后，开始学习 TurtleSim 仿真环境的使用。

首先运行：

```bash id="m8k1zp"
ros2 run turtlesim turtlesim_node
```

成功启动 TurtleSim 图形界面，可以看到绿色小乌龟以及蓝色背景窗口。

随后编写直行控制节点：

```bash id="x4v9ql"
python3 straight_mover.py
```

程序通过向 `/turtle1/cmd_vel` 话题持续发布 `Twist` 消息，实现对小乌龟的速度控制。

实验中设置：

```python id="r2p6dn"
linear.x = 2.0
angular.z = 0.0
```

表示小乌龟沿 X 轴方向持续直线运动。

通过实验，理解了：

* ROS2 Topic 通信机制
* Publisher 消息发布
* Twist 速度控制消息
* 机器人线速度与角速度控制原理
* 节点之间的实时通信方式

实验截图：

小乌龟直行控制

在实验过程中，可以明显看到小乌龟不断向前移动，并在屏幕中留下运动轨迹。这说明消息发布已经成功，ROS2 能够实时控制仿真机器人运动。

## 实验中遇到的问题

### 问题1：Python 节点无法运行

原因：

* 未执行 `rclpy.init()`
* 未调用 `rclpy.spin()`

解决方法：

* 检查节点初始化流程
* 保持节点持续运行

---

### 问题2：小乌龟不运动

原因：

* 未持续发布 `/turtle1/cmd_vel`
* Topic 名称错误

解决方法：

* 循环发送 Twist 消息
* 检查 Publisher 配置

---

### 问题3：轨迹运动不准确

原因：

* 时间控制误差
* 速度参数设置不合理

解决方法：

* 调整线速度
* 调整转向时间

---

### 问题4：PyBullet 无法打开 GUI

原因：

* WSL 图形环境未配置

解决方法：

* 在本地 Linux 图形环境运行
* 配置 X11 图形支持
