## PyBullet 仿真环境介绍

PyBullet 是一个常用的机器人仿真平台，能够实现：

* 刚体动力学模拟
* 机器人运动控制
* 多关节机械结构控制
* 碰撞检测
* 强化学习训练
* 三维物理环境模拟

相比简单二维仿真工具，PyBullet 能够更加真实地模拟机器人在现实环境中的运动状态，因此被广泛应用于：

* 四足机器人训练
* 机械臂控制
* 自动驾驶仿真
* AI 强化学习
* 智能机器人研究

本次实验主要使用 Python 调用 PyBullet API 完成基础机器人仿真。

## 安装仿真环境

首先安装 PyBullet：

```bash id="f8n3ya"
pip install pybullet
```

安装完成后，可以通过 Python 导入：

```python id="r4x6zm"
import pybullet as p
```

说明仿真环境已经配置成功。

此外，本次实验还使用了：

```python id="k7v9mt"
import pybullet_data
```

用于加载 PyBullet 自带的模型资源。

## 创建三维物理环境

在程序开始阶段，首先创建 PyBullet GUI 图形界面：

```python id="c3m8wb"
physicsClient = p.connect(p.GUI)
```

运行后，系统会自动打开一个三维窗口。

随后设置资源路径：

```python id="x2q4ln"
p.setAdditionalSearchPath(pybullet_data.getDataPath())
```

用于读取系统内置的：

* 地面模型
* 小球模型
* 机器人模型

等资源文件。

接着设置重力系统：

```python id="d5k1vz"
p.setGravity(0, 0, -9.8)
```

其中：

* X 轴重力 = 0
* Y 轴重力 = 0
* Z 轴重力 = -9.8

表示物体会受到地球重力影响向下运动。

通过本部分实验，理解了三维物理仿真中的：

* 坐标系统
* 重力系统
* 时间步长
* 物理计算

等基础概念。

## 加载地面与机器人模型

在完成物理环境创建后，开始加载地面模型：

```python id="q9v2pc"
planeId = p.loadURDF("plane.urdf")
```

程序运行后，仿真界面会显示一个平面地板。

随后加载机器人模型：

```python id="y1k7xd"
robotId = p.loadURDF(
    "r2d2.urdf",
    [0, 0, 0.2]
)
```

其中：

* `"r2d2.urdf"` 为机器人模型文件
* `[0, 0, 0.2]` 为机器人初始位置

URDF 是机器人系统中常见的模型描述格式，可以定义：

* 机器人结构
* 关节连接
* 碰撞模型
* 惯性参数
* 视觉模型

通过本部分实验，进一步理解了机器人模型在仿真系统中的加载方式。

## 机器人运动控制

完成模型加载后，开始控制机器人运动。

首先获取机器人关节数量：

```python id="u6w4qm"
num_joints = p.getNumJoints(robotId)
```

随后通过循环输出所有关节信息。

机器人运动主要通过：

```python id="e7t5np"
p.setJointMotorControl2()
```

函数实现。

实验中设置：

```python id="z8c1mv"
targetVelocity=10
```

用于控制机器人轮子转动速度。

程序持续执行：

```python id="p4n7lt"
p.stepSimulation()
```

实现物理系统实时更新。

在 GUI 界面中，可以观察到：

* 机器人轮子持续旋转
* 机器人向前移动
* 重力系统正常工作
* 碰撞检测实时生效

通过本部分实验，进一步理解了：

* 电机控制
* 关节运动
* 机器人动力学
* 速度控制机制

等内容。

## 三维机器人仿真特点

相比之前学习的 TurtleSim 二维仿真，PyBullet 三维仿真更加复杂。

TurtleSim 主要实现：

* 二维平面运动
* 简单速度控制
* 基础 Topic 通信

而 PyBullet 不仅需要控制机器人运动，还需要考虑：

* 重力影响
* 碰撞检测
* 多关节协调
* 三维空间位置
* 动力学计算

因此，PyBullet 更接近真实机器人系统。

目前很多强化学习机器人系统都会使用 PyBullet 进行训练，例如：

* 四足机器人
* 机械臂抓取
* 平衡机器人
* AI 自动控制系统

等。

## 实验中遇到的问题

### 问题1：PyBullet GUI 无法打开

原因：

* WSL 图形环境未配置
* 缺少显卡驱动支持

解决方法：

* 在本地 Ubuntu 图形环境运行
* 配置 X11 图形界面

---

### 问题2：机器人不运动

原因：

* jointIndex 设置错误
* 未调用速度控制函数

解决方法：

* 检查关节编号
* 使用 `VELOCITY_CONTROL`

---

### 问题3：机器人掉出地图

原因：

* 初始坐标设置错误
* 地面模型未加载

解决方法：

* 调整机器人初始位置
* 确认 `plane.urdf` 已正确加载

---

### 问题4：仿真卡顿

原因：

* CPU 性能不足
* GUI 渲染压力较大

解决方法：

* 关闭后台程序
* 降低图形窗口刷新频率
