## 坐标系基础学习

本周首先学习了机器人中的二维坐标系概念。

机器人运动中通常存在两种重要坐标系：

* 世界坐标系（World Coordinate）
* 机器人坐标系（Robot Coordinate）

世界坐标系通常固定不动，用于描述机器人在环境中的位置；机器人坐标系则会随着机器人移动而发生变化。

例如：

* 世界坐标系中的 `(0,0)` 一般表示地图原点
* 机器人坐标系原点通常位于机器人中心

通过学习坐标系概念，理解了机器人在运动时：

* 位置会发生变化
* 朝向会发生变化
* 坐标转换需要数学计算

## 坐标变换原理

随后学习了机器人运动中的坐标变换。

机器人在运动时，需要不断计算：

* 当前坐标
* 当前方向
* 下一时刻位置

机器人位置通常由：

```text id="h8m2vr"
x、y、θ
```

三个参数表示。

其中：

* `x` 表示横向位置
* `y` 表示纵向位置
* `θ` 表示机器人朝向角度

通过 TurtleSim 实验观察到：

* 当机器人向前运动时，x 或 y 会变化
* 当机器人旋转时，θ 会变化

同时了解到：

```text id="m6q1tx"
θ 使用弧度（rad）
```

例如：

```text id="t9v5zb"
90° ≈ 1.57 rad
180° ≈ 3.14 rad
```

通过不断观察小乌龟运动，加深了对角度变化与方向控制的理解。

此外，本周还学习了机器人位置更新的基本思想。当机器人不断接收到速度指令时，系统会根据：

* 当前速度
* 当前方向
* 时间变化

计算新的位置坐标。这也是机器人导航系统中的重要基础。

## 里程计（Odometry）学习

本周重点学习了机器人里程计的概念。

里程计主要用于估计机器人当前位置与运动轨迹。

在 ROS2 中，可以通过：

```bash id="n4v1yc"
ros2 topic echo /turtle1/pose
```

查看小乌龟当前位姿数据。

输出内容包括：

* x 坐标
* y 坐标
* theta 方向角
* linear_velocity
* angular_velocity

通过不断观察数据变化，可以清楚看到机器人运动过程中的实时状态。

* 位置信息

* 姿态信息

通过本部分学习，理解了机器人定位系统的基本工作方式。

## 差速驱动机器人运动学

随后学习了差速驱动机器人运动学模型。

差速驱动机器人通常由左右两个轮子组成。

机器人运动方式包括：

* 两轮同速 → 直线运动
* 左右轮速度不同 → 转弯
* 两轮反向 → 原地旋转

机器人运动与：

* 线速度
* 角速度
* 轮子速度

之间存在数学关系。

通过实验，理解了机器人运动控制不仅仅是简单移动，而是需要根据运动学公式不断更新位置。

同时还学习了机器人位置更新公式：

```text id="r1y6zd"
x = x + v cos(θ) dt
y = y + v sin(θ) dt
θ = θ + ω dt
```

其中：

* `v` 为线速度
* `ω` 为角速度
* `dt` 为时间变化量

通过这些公式，机器人能够不断计算自己的位置。

## 正运动学与逆运动学

本周还初步学习了：

* 正运动学（Forward Kinematics）
* 逆运动学（Inverse Kinematics）

正运动学：

已知关节角度，求机械臂末端位置。

逆运动学：

已知目标位置，反向计算各关节角度。

通过机械臂示意图，理解了机械臂运动与角度之间的关系。

同时还学习了机器人自由度（DOF）的概念。

自由度越高，机器人运动能力越强，但控制难度也会增加。
