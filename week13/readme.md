## 📚 理论基础

### 1️⃣ 为什么需要四足机器人？

轮式机器人在平坦地面效率较高，但在复杂环境（如楼梯、碎石、山地）中适应性较差。
四足机器人通过多腿协调运动，提高地形适应能力，适用于：

* 巡检任务
* 灾后救援
* 山地探索
* 非结构化环境作业

---

### 2️⃣ 四足机器人结构

四足机器人由四条腿组成：

* LF（Left Front）：左前腿
* RF（Right Front）：右前腿
* LH（Left Hind）：左后腿
* RH（Right Hind）：右后腿

每条腿通常包含多个关节：

* 髋关节
* 膝关节
* 踝关节

---

### 3️⃣ 控制思想

四足机器人控制系统需要综合考虑：

* 身体稳定性控制
* 步态规划（Gait Planning）
* 足端接触检测
* 关节角控制
* 姿态反馈（IMU）

现代方法常结合：

* 模型预测控制（MPC）
* 强化学习（RL）
* 仿真训练（Sim-to-Real）

## 🧠 仿真实验（Python）

本实验使用 Python 编写简化四足机器人步态模拟程序，用于理解 **对角步态（Trot Gait）** 的基本逻辑。

### 📌 核心思想

四条腿交替分组：

* 支撑腿（Support Legs）
* 摆动腿（Swing Legs）

实现身体稳定前进。

---

---

### 🧾 示例代码

```python
import time

print("Week 13：四足机器人步态模拟")
print("--------------------------------")

print("四足机器人基本结构：")
print("LF：左前腿")
print("RF：右前腿")
print("LH：左后腿")
print("RH：右后腿")

print("--------------------------------")
print("开始模拟 Trot 对角步态")

for step in range(1, 7):
    print(f"Step {step}")

    if step % 2 == 1:
        print("支撑腿：LF + RH")
        print("摆动腿：RF + LH")
    else:
        print("支撑腿：RF + LH")
        print("摆动腿：LF + RH")

    print("身体保持平衡，进入下一步")
    print("--------------------------------")
    time.sleep(0.3)

print("四足机器人步态模拟完成")
```
