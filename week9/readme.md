第 9 周：机器人与机器数学视觉基础
本周主要围绕机器人与机器系统中的数学基础展开学习，重点从空间表达、运动建模、视觉处理到路径规划逐步建立完整知识框架，为后续机器人控制与智能算法打下基础。

首先从线性代数基础出发，重点复习矩阵及其运算性质。矩阵不仅用于数值计算，更重要的是作为空间变换的统一表达工具。在机器人系统中，点、向量以及姿态信息通常都可以通过矩阵形式进行描述，从而将复杂的几何问题转化为代数运算问题，提高计算效率与表达一致性。

在此基础上进一步学习坐标变换与旋转矩阵。坐标变换用于解决不同参考系之间的表达一致性问题，而旋转矩阵则用于描述刚体在空间中的姿态变化。通过二维与三维旋转的推导，可以加深对欧拉角、方向余弦矩阵等表示方法的理解，同时也能够比较不同表示方式在数值稳定性与计算复杂度上的差异。

随后进入机器人运动学部分（机器人运动学）。该部分重点研究机械结构与末端执行器之间的映射关系，包括正运动学与逆运动学两类核心问题。正运动学通过已知关节参数计算末端位姿，而逆运动学则根据目标位姿反求关节变量，通常存在多解性或无解析解情况，因此常结合数值迭代方法进行求解，例如牛顿法或梯度下降法等，从而获得可行解或近似最优解。

在视觉部分学习了图像非线性处理相关内容。真实成像过程中会受到透视投影、镜头畸变等因素影响，使图像与真实空间之间产生非线性映射关系。因此需要通过标定与非线性校正模型进行修正，使图像恢复到更接近真实几何结构的状态，为后续目标识别与定位提供可靠输入。

最后学习路径规划算法，重点理解在复杂环境中如何搜索可行路径的问题。常见方法包括基于图搜索的A*算法以及基于随机采样的RRT算法等。这些方法的核心思想是在约束条件下寻找一条代价函数最优或近似最优的路径，同时兼顾计算效率与实时性要求，在动态环境中还需要结合局部避障策略进行优化。

总体来看，本周学习内容形成了从数学表达到空间建模，再到感知处理与路径决策的完整链条，使机器人系统的基础逻辑更加清晰，为后续深入研究控制系统、强化学习与自主导航等方向奠定了坚实基础。
理论整理
1.为什么机器人需要数学？
机器人需要用数学模型描述位置、姿势、速度和运动过程。
例如坐标变换表示可以机器人从一个位置移动到另一个位置。

2. 旋转矩阵
二维旋转矩阵可以表示平面中点的旋转：

R = [[cosθ, -sinθ], [sinθ, cosθ]]

3.机器人运动学
机器人运动学研究机器人位置、速度和关节之间的关系。
常见内容包括正运动学、逆运动学和雅可比矩阵。

4. 视觉机器数学
机器视觉中常用图像矩阵、结构、提取等方法处理图像信息。

5.路径规划
常见路径规划算法包括BFS、Dijkstra、A*、RRT和DWA。
