# 第五周实验报告：机器人传感器与 RViz 可视化学习

本周完成的主要任务如下：

* 学习机器人常用传感器分类
* 理解外部传感器与内部传感器区别
* 学习激光雷达（LiDAR）测距原理
* 了解相机与图像传感器基础
* 学习 ROS2 中常见传感器话题
* 学习 `/scan` 与 `/image` 数据结构
* 掌握 RViz 可视化工具使用方法

通过本周实验，进一步理解了机器人感知系统在智能机器人中的重要作用。

## 机器人传感器基础学习

机器人系统通常需要依赖不同类型的传感器获取环境信息。

本周首先学习了机器人传感器分类。

机器人传感器主要分为：

* 外部传感器
* 内部传感器

外部传感器主要用于感知机器人周围环境，例如：

* 激光雷达（LiDAR）
* 摄像头（Camera）
* 深度摄像头
* 超声波传感器

内部传感器主要用于检测机器人自身状态，例如：

* 编码器
* IMU 惯性传感器
* 电机速度传感器
* 电池电压检测

通过学习这些内容，进一步理解了机器人系统中的“感知层”概念。机器人之所以能够导航、避障以及识别环境，核心原因就是能够通过传感器不断获取外部世界的信息。

机器人系统通常会同时使用多种传感器。例如：

* 激光雷达用于测距
* 摄像头用于图像识别
* IMU 用于检测姿态变化
* 编码器用于计算轮子运动距离

多个传感器数据结合后，机器人才能更加准确地感知环境。

## 激光雷达（LiDAR）学习

本周重点学习了激光雷达（LiDAR）的工作原理。

激光雷达通过发射激光并测量反射时间计算距离，从而实现环境测距。

LiDAR 的主要特点包括：

* 测距精度高
* 数据更新速度快
* 适合机器人导航
* 可生成二维或三维点云

在 ROS2 中，激光雷达通常会发布：

```text id="f6v2yt"
/scan
```

话题。

可以通过：

```bash id="x8m4kc"
ros2 topic echo /scan
```

查看激光雷达数据。

输出内容通常包括：

* angle_min
* angle_max
* range_min
* range_max
* ranges[]

其中：

```text id="u9w3rb"
ranges[]
```

数组表示不同方向上的距离数据。

通过观察这些数据，进一步理解了机器人如何利用激光雷达检测周围障碍物。

在 RViz 中，还能够将激光雷达数据显示为：

* 激光点
* 扇形扫描区域
* 障碍物轮廓

通过动态变化的数据，可以明显观察到机器人周围环境的变化情况。

## 相机与图像传感器学习

除了激光雷达，本周还学习了机器人中的相机传感器。

相机能够获取：

* 彩色图像
* 灰度图像
* 深度图像

等数据。

图像传感器通常用于：

* 目标识别
* 路径识别
* 人脸识别
* 自动驾驶视觉系统

在 ROS2 中，相机数据通常通过：

```text id="k5n1zx"
/image
```

话题发布。

本周实验中学习了图像数据传输与显示的基本方法，并通过：

```bash id="y4q7vm"
ros2 run image_transport republish raw
```

实现图像数据处理。

通过学习图像传感器，进一步理解了机器人视觉系统的重要性。相比激光雷达只能获取距离信息，摄像头能够获取更加丰富的环境细节，因此在 AI 智能机器人中应用十分广泛。

## RViz 可视化工具学习

本周重点学习了 RViz 可视化工具。

RViz 是 ROS 中非常重要的可视化软件，可以实时显示：

* 激光雷达数据
* 地图信息
* 机器人模型
* 位姿信息
* 路径规划结果
* 摄像头图像

等内容。

启动 RViz：

```bash id="m1v8pn"
rviz2
```

打开 RViz 后，可以添加：

* LaserScan
* Image
* RobotModel
* TF
* Pose

等显示模块。

本次实验中重点完成了：

* 激光雷达显示
* 位姿显示
* 图像数据显示

通过 RViz 可以更加直观地观察机器人感知系统运行状态。

## ROS2 传感器话题学习

本周还重点学习了 ROS2 中常见传感器话题。

例如：

查看所有话题：

```bash id="z2m6pc"
ros2 topic list
```

筛选激光雷达话题：

```bash id="v4n1yr"
ros2 topic list | grep scan
```

监听激光雷达数据：

```bash id="c8w3tx"
ros2 topic echo /scan
```

查看位姿信息：

```bash id="f9q5zm"
ros2 topic echo /odom
```

通过这些命令，进一步理解了 ROS2 中：

* Topic 通信
* Publisher
* Subscriber
* 数据流

等核心概念。

## 实验中遇到的问题

### 问题1：RViz 无法显示数据

原因：

* Fixed Frame 设置错误
* 坐标系不一致

解决方法：

* 检查 map/world/odom 设置
* 确认 TF 正常发布

---

### 问题2：无法看到激光雷达数据

原因：

* `/scan` 话题不存在
* 激光雷达节点未启动

解决方法：

* 检查 Topic
* 确认仿真环境正常运行

---

### 问题3：图像无法显示

原因：

* 图像话题名称错误
* 图像类型不匹配

解决方法：

* 检查 `/image` 话题
* 确认图像编码格式

---

### 问题4：Gazebo 运行卡顿

原因：

* 电脑性能不足
* 图形渲染负载较高

解决方法：

* 关闭后台程序
* 降低仿真复杂度
